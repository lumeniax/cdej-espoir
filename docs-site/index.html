Cette page est une vitrine du projet

CDEJ Espoir est une application full-stack qui nécessite un serveur Node.js (Express), une base PostgreSQL et de l'authentification JWT par cookies httpOnly. GitHub Pages étant un hébergement statique, l'application ne peut pas fonctionner ici. Pour l'utiliser réellement, suivez les instructions d'installation ci-dessous ou consultez DEPLOYMENT.md.

Stack technique moderne

Construit avec les meilleurs outils de l'écosystème JavaScript / TypeScript en 2025.

🎨 Frontend

  • React 19 + Vite 7
  • Tailwind CSS 4 + shadcn/ui
  • React Query 5 + Wouter
  • Dexie.js (offline IndexedDB)
  • Zod v4 (validation)

⚙️ Backend

  • Express 5 + Node.js 24
  • TypeScript 5.9
  • Drizzle ORM + PostgreSQL 15
  • OpenAPI + génération Orval
  • pnpm workspaces (monorepo)

🔒 Sécurité

  • Argon2id (hash des mots de passe)
  • JWT HS256 (accès 15 min)
  • Cookie httpOnly (refresh 7 j)
  • 6 rôles (RBAC complet)
  • Audit log de toutes les actions

Installation locale

Suivez ces étapes pour faire tourner CDEJ Espoir sur votre poste de développement.

1

Prérequis

  • Node.js 24+
  • pnpm 10+
  • PostgreSQL 15+
2

Cloner le dépôt

git clone https://github.com/lumeniax/cdej-espoir.git
cd cdej-espoir
pnpm install
3

Configuration

cp .env.example .env
# éditer .env :
# DATABASE_URL, JWT_SECRET,
# REFRESH_SECRET, SESSION_SECRET
4

Base de données

pnpm --filter @workspace/db run push
pnpm --filter @workspace/api-server run seed
5

Lancer le projet

# Terminal 1 - API
pnpm --filter @workspace/api-server run dev

# Terminal 2 - Frontend
pnpm --filter @workspace/cdej-espoir run dev
6

Déploiement Docker

docker-compose up -d
# voir DEPLOYMENT.md pour la prod
