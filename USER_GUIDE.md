# CDEJ Espoir TG0154 — Guide utilisateur

## Connexion

1. Ouvrez l'application dans un navigateur
2. Entrez votre adresse email et mot de passe
3. Cliquez sur **Se connecter**

> **Astuce :** L'application peut être installée comme application mobile (PWA) en cliquant sur "Ajouter à l'écran d'accueil" dans votre navigateur.

---

## Gestion des participants

### Ajouter un participant

1. Cliquez sur **Participants** dans le menu
2. Cliquez sur **Nouveau participant**
3. Remplissez les informations obligatoires (nom, prénom, date de naissance, sexe)
4. Les informations facultatives peuvent être complétées plus tard
5. Cliquez sur **Enregistrer**

Le système attribue automatiquement un identifiant unique au format `TG015400XXX`.

### Recherche rapide

Utilisez le raccourci clavier **Ctrl+K** (ou **Cmd+K** sur Mac) pour ouvrir la recherche globale et trouver rapidement un participant.

### Modifier un participant

1. Cliquez sur le nom du participant dans la liste
2. Cliquez sur **Modifier**
3. Apportez les modifications
4. Cliquez sur **Enregistrer**

---

## Saisie des présences

### Mode en ligne

1. Allez dans **Présences**
2. Sélectionnez l'enseignant et la date de session
3. Cliquez sur **Créer la session**
4. Cochez/décochez chaque enfant (Présent / Absent)
5. Cliquez sur **Enregistrer les présences**

### Mode hors ligne

Si vous n'avez pas de connexion internet :
1. L'application détecte automatiquement la perte de connexion
2. Une bannière "Vous êtes hors ligne" s'affiche
3. Vous pouvez quand même saisir les présences — elles sont sauvegardées sur votre appareil
4. Quand la connexion revient, l'application synchronise automatiquement les données
5. Vous pouvez aussi cliquer sur **Synchroniser maintenant** manuellement

---

## Suivi IMC

1. Allez dans **Suivi IMC**
2. Sélectionnez un participant
3. Entrez les mesures (poids, taille)
4. Le système calcule automatiquement l'IMC et la classification OMS
5. L'historique des mesures est conservé

Classifications OMS :
- **Émacié sévère** : IMC-pour-âge < -3 Z-score
- **Émacié** : IMC-pour-âge entre -3 et -2 Z-score
- **Normal** : IMC-pour-âge entre -2 et +1 Z-score
- **Surpoids** : IMC-pour-âge entre +1 et +2 Z-score
- **Obèse** : IMC-pour-âge > +2 Z-score

---

## Fiches de paiement

1. Allez dans **Fiches de paiement**
2. Cliquez sur **Nouvelle fiche**
3. Sélectionnez le participant et le type de financement
4. Entrez le montant et la date
5. Joignez un justificatif si disponible

---

## Profil et mot de passe

1. Cliquez sur votre nom en bas du menu
2. Sélectionnez **Mon profil**
3. Modifiez votre nom d'affichage si nécessaire
4. Pour changer de mot de passe, remplissez la section **Sécurité**

---

## Mode sombre / clair

Cliquez sur l'icône lune/soleil dans le menu pour basculer entre le mode clair et le mode sombre.

---

## Export des données

1. Allez dans **Import/Export**
2. Choisissez le type de données à exporter (participants, présences, etc.)
3. Sélectionnez le format (Excel ou CSV)
4. Cliquez sur **Exporter**

---

## Notifications et alertes

Les alertes d'absences répétées sont créées automatiquement. Pour les consulter :
1. Cliquez sur **Notifications** dans le menu
2. L'icône de cloche indique le nombre de notifications non lues

## Dépannage

**L'application ne charge pas :**
- Vérifiez votre connexion internet
- Videz le cache du navigateur (Ctrl+Maj+R)
- Réessayez avec un autre navigateur

**Les données ne s'enregistrent pas :**
- Vérifiez que vous avez les permissions nécessaires pour cette action
- Vérifiez si vous êtes en mode hors ligne (les présences sont sauvegardées localement)

**Mot de passe oublié :**
- Contactez votre administrateur pour réinitialiser votre mot de passe
